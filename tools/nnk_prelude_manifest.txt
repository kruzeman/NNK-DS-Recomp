# Ni no Kuni DS — prelude feature manifest (Phase-5AG)
#
# WHY THIS FILE EXISTS
# tools/build_split.sh compiles a FROZEN dispatch image (work/phase3a/
# arm9_thumb_ovl_itcm_p5u.c) that `nnktool recompile-all` generated at an
# earlier phase.  The canonical runtime ("prelude") of the current tree lives
# in nnktool/src/recompile.rs, in the tools/*.inc fragments that the image
# #includes, and in the transforms tools/split_dispatch.py and the splice
# scripts apply at build time.  A prelude fix committed to the tree is
# therefore NOT in the shipped binary unless one of those three paths carries
# it -- and nothing used to notice.  Phase-5AB (missing VRAM read shadow ->
# 0x020E1B32 crash) and Phase-5AF (missing overlay registry -> only 2 overlay
# slots) were both that class, discovered hours late.
#
# Every row is:  id <TAB> class <TAB> marker <TAB> source <TAB> description
#
#   class = required    the EFFECTIVE prelude must contain `marker`, and the
#                       tree file `source` must contain it too (so the manifest
#                       cannot rot into a test of nothing).  A missing marker
#                       FAILS the build (tools/prelude_audit.py, called from
#                       tools/build_split.sh after the split, before cc).
#   class = divergent   the tree carries the marker but the frozen image
#                       predates it.  Expected ABSENT from the effective
#                       prelude; the audit reports it as "image predates the
#                       tree" and tells a future phase to promote the row after
#                       it splices the fix.  Not enforced: shipping these
#                       changes guest-visible behaviour, which needs its own
#                       measured phase.
#   class = obsolete    the frozen image carries the marker, the tree dropped
#                       it.  The audit reports it as a stale probe so it can be
#                       dropped or re-spliced; not fatal (probes only).
#
# The search space for `required` is the effective prelude text: the split's
# nnk_main.c (image prelude + every split-time injection) plus every *.inc
# copied next to it.  That is exactly what cc compiles as the runtime TU.
#
# RULE FOR A FUTURE PHASE: when you add or change a prelude feature, add a row
# here in the same commit, with the marker being a symbol/expression that only
# that feature introduces.  Run `bash tools/build_split.sh <out>`: if the audit
# fails, your feature is missing from the shipped binary -- splice it (see
# tools/p5*_splice.py) or regenerate the image.  Full mechanics: PRELUDE_AUDIT.md
