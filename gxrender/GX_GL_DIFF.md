# GL-vs-SOFTWARE per-unit diff tables (Phase-3B3)

Committed deliverable for task "OpenGL render engine validated against the
software reference" -- traces/ is gitignored, so the measured per-unit
numbers live here.  All numbers below were produced by the exact repro
commands in the last section on Mesa llvmpipe (LLVM 20.1.2) under Xvfb.

Units are 256x192 px = 49152 px per screen buffer.  "diff px" is the
count of pixels that differ in any channel; max delta is the largest
per-channel absolute difference (8-bit channel values).

## canon2d (820 units) -- 2D GPU compositor vs software reference

GL-vs-SOFTWARE (the primary acceptance comparison):

- units: **820 / 820 byte-identical**
- pixels: 0 differing of 80,609,280 -- **100.0000% exact**, max delta 0
- GL-vs-melonDS golden (secondary): 65,024 px differ (0.0807%), all of
  them unit 14444 (max delta 207).  This is the software path's own
  accepted 2D residual class (software-vs-melonDS canon2d baseline is
  99.92%); GL == software byte-for-byte on every unit, so this is not a
  GL divergence.

Two real-capture bugs were found and fixed in this round (both invisible
to the previous synthetic tests, now pinned by test cases C6/C7):

1. **BG2 affine-ref latch mixup** (units 6000-6050 / 9000-9050 classes,
   mode 5 extended bitmap): the compositor shader passed lat0.z/lat0.w
   (the BG3 ref latch texel) to BG2's extended/affine/large evaluators
   instead of lat0.x/lat0.y.  When BG3 was disabled its latch never
   advances (layer-enable gate in the PreDraw/PostDraw model), so BG2
   sampled a frozen reference and rendered one bitmap row across the
   whole screen.  Fix: src/gx_gl2d.c uses lat0.x/lat0.y for BG2.
   Regression test: tests/test_gl2d.c C6 (unit-9020 register mix).
2. **16-color text palette-bank byte offset** (units 21000-21050 class,
   bgcnt 0x2600): palbase added bank*16 as a byte offset where the
   software adds bank*16 entries (bank*32 bytes), so tiles from palette
   banks >= 1 read the wrong palette entries.  Fix: src/gx_gl2d.c
   multiplies the bank offset by 2.  Regression test: tests/test_gl2d.c
   C7 (unit-21010 register class).
